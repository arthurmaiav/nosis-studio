# Return Money Bag

The return money bag is the single movable prop in the failed-return and repayment shots. It is a full tan burlap sack with the Nosis cat coin emblem, a wide weighted base, and a tightly cinched neck. It stays closed and appears exactly once.

The approved visual sheet locks the pouch front, side, held, and half-inserted states. Use it in every failed-return and repayment frame so the model never redesigns the prop.
