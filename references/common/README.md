# Common visual assets

Common assets are references reused by more than one character or episode.

Every asset uses this folder contract:

```text
common/<category>/<asset-id>/
  asset.json
  asset.md
  master.png or master-sheet.png
  optional state or angle sheets
```

Use one approved reference per visual responsibility. A set master locks environment geometry. A token sheet locks logo, shape, and material. A prop sheet locks size, count, orientation, and permitted states.

Do not attach an entire common library to one generation. The shot manifest selects only the references required for that composition.
